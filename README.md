# Digital Silt Passport

Proposed QR-based Digital Silt Passport pilot for canal reaches.

## Access model
- QR/public visitor: **Read only**
- Approved staff: authenticated edit access
- Master admin: approve/revoke staff, manage reaches, review records and audit log

## Pilot reach
Kithore Minor — RD 2.400–3.100 km

## Important
This repository currently contains the public frontend prototype. Real authentication, database, photo storage and server-side authorization must be implemented before production use. Do not store passwords or secrets in this repository.
